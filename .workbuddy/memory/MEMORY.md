# 项目长期约定（YOCIM-AGENT）

- **文档策略**：`docs/realized(已实现)/WORKSPACE_PANEL_PLAN.md` 是用户自己维护的阶段计划（P0–P6 完成后已归档到此路径，`docs/` 根下不再有该文件）。用户明确要求「不用另起文档」——阶段状态、验收结果、偏差说明、交接坑位一律就地更新该文档，不要另建计划/交接文档。README 有过期 UI 描述时同步修正。
- **验证基线**：`npm test`（单测）、`npm run typecheck`、`npm run lint`、`npm run format:check`、`npm run e2e`。在 WorkBuddy 会话里跑 e2e 必须去掉继承的 `ELECTRON_RUN_AS_NODE=1`：`env -u ELECTRON_RUN_AS_NODE npm run e2e`，否则 Electron 以 Node 模式启动并报 `bad option: --remote-debugging-port=0`。同一环境里 `npm test` 默认线程池会抛 `Vitest failed to find the runner`（沙箱 `NODE_OPTIONS` shim 与 tinypool 冲突，与本项目无关），改用 `npx vitest run --pool=vmThreads`。
- **IPC 铁律**：传给 `window.yocim.*` invoke 的参数必须是纯数据，不能是 Vue reactive Proxy（`ref.value` 里的对象/数组），否则 invoke reject 表现为「主进程无响应」；P1、P2 各踩过一次。
- **阶段进度**：P0–P4 已提交（`f2a6528`），P5（WSL + SSH 远程）与 P6（回归与交付）已完成但**未提交**；工作区面板计划文档已归档。WSL/SSH 的**成功路径仍无真机验收**（本机 `wsl.exe` 被安全策略拦截、无 SSH 服务器），是后续第一优先项。
- **未落地偏差**：大纲仍用正则提取（未接 Monaco TS Worker）、无 fs watcher（靠保存/切换标签时 hash 比对）、ripgrep 二进制未打包（留到 P6 `electron-builder.yml` extraResources）、`.gitignore` 与 glob 为简化实现、Git 路径基准是工作区根而非仓库根、放弃更改拒绝未跟踪文件；调试是自研 CDP 而非 DAP/js-debug（只支持 Node launch，无 attach）、`launch.json` 无 JSON Schema 校验、VSIX 用自研最小 zip、扩展语法/主题贡献只展示不生效。详见计划文档 §14.3。
- **打包铁律**：`electron-builder.yml` 用 `extraResources` 把 `resources/ripgrep` 放到安装包 `resources/ripgrep`；`files` 显式列 `zod` + `ssh2` 及依赖并排除 `cpu-features/nan/buildcheck`；必须 `npmRebuild: false`（ssh2 可选原生依赖 + 项目路径含空格会让 node-gyp 失败）。
- **远程架构**：WSL 用 `\\wsl.localhost\<distro>\...` UNC 根复用本地 fs，只有 Git/搜索/任务走 `wsl.exe --cd/--exec`；SSH 用 ssh2（SFTP 文件 + exec 命令）+ `RemotePathGuard` 虚拟守卫。切换靠 `src/main/remote/execRegistry.ts` 的模块级 `RemoteExec`，`gitRunner`/`searchService`/`taskService` 都内置了远程分支；新增走系统的服务时要先看 `getRemoteExec()`。
- **本会话构建铁律**：`npm run build` 必须非沙箱执行**且** `env -u NODE_OPTIONS`（沙箱 safe-delete shim 会拒绝清理 `out/renderer/assets`，报 `SAFE_DELETE_BULK_CONFIRM_REQUIRED`），否则会「构建失败但 e2e 用旧产物通过」；打包同理要 `-c.directories.output=%TEMP%/...`（E: 盘 rename 会 EPERM）。Playwright 会清空 `test-results/`，临时脚本放 `build/` 并在收尾删除。
- **调试铁律**：在 Electron 主进程里 spawn 调试目标必须注入 `ELECTRON_RUN_AS_NODE=1`（`process.execPath` 是 electron.exe），否则目标被当 Electron 应用启动、永不命中用户断点；`DebugService.start` 必须先 `setBreakpoints` 再 `start()`；`executionContextDestroyed` 后要主动 `cdp.close()` 否则子进程不退出。
- **Agent 工具层（P0 之后）**：工具实现在 `src/main/tools/` 按职责拆成 `listTools/readTools/searchTools/editTools`（`workspaceTools.ts` 只是 barrel），文件访问一律走 `ToolFileIo`（`toolFileIo.ts`），**不要在工具里直接 import `node:fs`**——SSH 远程要补 `createRemoteToolFileIo` 就靠这个接缝。新工具要同步四处：`shared/tools.ts`（定义 + 摘要 + `isWriteTool`）、`toolSchemas.ts`（zod）、`*-Tools.ts`（实现）、`toolService.ts`（`TOOL_RISK` + `runParsed` 分支 + 写后快照）。搜索走注入的 `ToolSearchRunner`（`createSearchServiceRunner` 包 `SearchService`），不要另写一套 rg spawn。
- **Agent 记忆**：Coding 能力路线图在 `docs/AGENT_CODING_CAPABILITY_PLAN.md`，P0 已实现并就地记录在 §11（含偏差与遗留项，如 SSH 只能搜不能改、历史不回放工具结果、轮次上限 6）。
- **时间线 UI 层**：工具活动流的展示逻辑在 `src/renderer/src/lib/timeline.ts`（纯函数：时长格式化、参数摘要拆工具名、图标分类、状态文案）+ `components/ToolIcon.vue`（按工具族分图标）+ `components/AgentTimeline.vue`（活动流视觉）。改这个组件时守住两条 e2e 红线：① summary 里的「已执行 N 个步骤」必须留在同一个元素内（e2e 用 `toContainText` 断言），时长只能放右侧独立元素；② **不要做「运行中自动展开」**——`context.spec` 会在 run 未结束时点 `timeline-toggle`，自动展开会让那次点击变成收起从而断言失败。
- **设置弹窗结构**：`SettingsDialog.vue` 是「左侧标签栏 + 右侧内容」外壳，六个面板在 `src/renderer/src/components/settings/`（Models/Billing/Search/Appearance/Storage/Browser）。**默认分页必须是「模型」**，且弹窗内**只能有一个含「关闭」二字的元素**（e2e 用 `getByText('关闭')` substring 匹配 + 严格模式）；面板文案禁用「关闭」二字。新增设置项的通用样式用 `main.css` 的 `.sp-*` 类。
- **设置存取铁律**：`SettingsRepository.set` 自己会 `JSON.stringify`，**存对象不要再手动 stringify**（双重编码会让 normalize 函数读到字符串）；`normalize*` 函数统一兼容「已经是字符串」的形态。`readStorage` 返回 null 时**必须先判空再 `Number()`**——`Number(null)` 是 0，会把字号夹到 10、侧栏宽度夹到 220（曾因此让 `fileExplorer.spec.ts` 被 Monaco minimap 挡住点击而变红）。
- **联网搜索**：`web_search` 工具（Tavily，`src/main/tools/webSearchTools.ts`），Key 在「设置 → 搜索」配。**没配 Key 时 `ToolService.getDefinitions()` 要把该工具过滤掉**，否则模型会反复调用必然失败的工具；`AgentService.toolDefinitions` 支持传 getter 函数，保证改设置后无需重启即可生效。
- **账单与用量**：token 用量由各 Provider 在流里上报（OpenAI 兼容发 `stream_options.include_usage`，服务端 400 时自动去掉重试一次；Anthropic `message_start`/`message_delta`；Gemini `usageMetadata`），`agentEngine` 在 `finally` 里上报（报错/取消也要记账），落到 `agent_usage` 表（schema v9）。费用 = 用量 × 「设置 → 账单」里手填的单价。
- **存储目录**：`boot/storage.json`（写在系统默认 userData 下）是数据目录的权威来源，db 在数据目录里会跟着搬走所以不能只存 db；改目录**重启后生效**（db 句柄运行期不能换），`main/index.ts` 启动时 `resolveDataDir(userData)`，扩展/日志/时间线/workspace.json 都跟着走。
